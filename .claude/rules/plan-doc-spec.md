# Plan 文档规范

创建或修改 plan 文档（文件名含 `plan` 或 `计划`）时，必须包含：
1. 版本目标（含"为什么"）
2. 文档锚定（锚定架构文档 + 同步更新清单）
3. 决策清单（分核心/支撑两层，含选项 + 状态）
4. 任务清单（分阶段，含验收标准 + 失败路径）
5. 执行规则（硬性约束 + 自主推进规则：自检通过自动继续，仅 `[需确认]` 任务需等待）
6. 执行记录（增强关键checkpoint的可观测性）
7. 执行 prompt 模板（任务范围化的 agent prompt，含硬性约束提取）

定位：MVP 构建和版本迭代的主线开发。package 配置、bug 修复等边界工作不纳入计划文档。

执行计划时，先读取"执行 prompt 模板"节，按单个任务（T{X.X}）范围化后填入 agent prompt。
参考：`.claude/rules/plan-execution.md`

参考模板：`docs/plan-checklist.md`
