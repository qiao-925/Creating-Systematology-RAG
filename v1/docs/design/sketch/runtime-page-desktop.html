根据文献分析[1][2]，新能源补贴政策通过三条主要路径影响碳排放：

财政激励路径：直接补贴降低企业研发成本[3]，加速清洁能源技术商业化。但长期依赖补贴可能产生"补贴依赖症"，削弱企业自主创新动力[4]。

技术创新路径：补贴带动的研发投入通过"干中学"效应降低技术成本[5]，形成正向反馈循环。EU ETS 数据显示碳价每上涨 10%，清洁技术专利申请增加 3.2%[6]。

市场结构路径：补贴改变能源市场相对价格[7]，加速化石能源退出。但需警惕"绿色悖论"——预期的碳约束可能导致化石能源提前开采[8]。
