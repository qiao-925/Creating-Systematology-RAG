基于系统性文献分析，城市化对居民心理健康的影响通过四条主要因果路径发挥作用12：


1. 环境压力路径：城市化 → 噪音/空气污染 → 慢性应激 → 焦虑/抑郁风险上升3

2. 社会资本路径：快速城市化 → 社区瓦解 → 社会支持网络弱化 → 心理韧性下降1

3. 生态暴露路径：城市扩张 → 绿地空间压缩 → 自然接触减少 → 注意力恢复不足4

4. 经济竞争路径：城市化 → 生活成本上升 → 经济压力 → 心理健康恶化2
